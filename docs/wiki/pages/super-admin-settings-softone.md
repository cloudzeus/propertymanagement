## Τι βλέπετε εδώ
Η φόρμα σύνδεσης (serial, χρήστης, κωδικός, APPID, εταιρεία/υποκατάστημα/module), το κουμπί δοκιμής σύνδεσης με την «Τελευταία δοκιμή σύνδεσης», οι ενότητες συγχρονισμού βασικών αρχείων (με dry-run «χωρίς εγγραφή») και το ιστορικό.

## Βήμα-βήμα
1. Συμπληρώστε τα στοιχεία του Web Account και πατήστε δοκιμή. Στα μηνύματα σφάλματος: «ελέγξτε serial, username, κωδικό και APPID» ή «ελέγξτε COMPANY / BRANCH / MODULE / REFID».
2. Τρέξτε πρώτα συγχρονισμό σε dry-run για να δείτε «τι θα στελνόταν», μετά κανονικά.
3. Λεπτομέρειες στο εγχειρίδιο «Διασύνδεση SoftOne ERP».
