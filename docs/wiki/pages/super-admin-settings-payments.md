## Τι βλέπετε εδώ
Η φόρμα με τα διαπιστευτήρια Viva της εταιρείας (Client ID / Secret, Merchant ID, API key, Source code) και ο διακόπτης ενεργοποίησης. Τα μυστικά αποθηκεύονται κρυπτογραφημένα· αν λείπουν, χρησιμοποιούνται οι μεταβλητές περιβάλλοντος.

## Βήμα-βήμα
1. Αντιγράψτε τα κλειδιά από το Viva Self Care (demo ή production) και αποθηκεύστε.
2. Ενεργοποιήστε τις πληρωμές· οι πελάτες μπορούν πλέον να πληρώνουν τα πακέτα τους με κάρτα.
3. Για τις εισπράξεις κοινοχρήστων από ενοίκους, κάθε πελάτης ορίζει δικό του λογαριασμό Viva στην καρτέλα της ιδιοκτησίας του — ποτέ ο λογαριασμός της εταιρείας.
