## Τι βλέπετε εδώ
Λίστα ιδιοκτησιών με καρτέλες «Στον χάρτη» / «Χωρίς θέση», πελάτη, κτήρια και μονάδες.

## Βήμα-βήμα
1. Πατήστε μια ιδιοκτησία για την καρτέλα της.
2. Για δημιουργία/επεξεργασία χρησιμοποιήστε τη λίστα «Ιδιοκτησίες» του Super Admin ή το δέντρο «Πελάτες».
