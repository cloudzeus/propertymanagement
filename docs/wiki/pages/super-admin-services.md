## Τι βλέπετε εδώ
Πίνακας υπηρεσιών: «Κωδικός», «Υπηρεσία», «Τύπος», «Τρόπος χρέωσης» («Σταθερή / μήνα», «Ανά μονάδα / μήνα», «Ανά κτήριο / μήνα», «Ανά κοινόχρηστο χώρο / μήνα», «Με μέτρηση + προαγορά»), «Τιμή (€)», «Κατάσταση» («Ενεργή»/«Ανενεργή»).

## Βήμα-βήμα
1. «Νέα Υπηρεσία»: «Κωδικός» (υποχρεωτικός), «Όνομα», «Σύντομη περιγραφή», «Τρόπος χρέωσης», «Τιμή (€/μήνα)».
2. Η υπηρεσία γίνεται διαθέσιμη στο «Πακέτο Υπηρεσιών» κάθε ιδιοκτησίας.
3. Για τις μετρούμενες υπηρεσίες (AI, βίντεο, απομαγνητοφώνηση) δείτε «Πακέτα Χρεώσεων».
