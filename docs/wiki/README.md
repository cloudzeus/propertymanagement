# PropertyPro — Wiki & εγχειρίδια

Τα εγχειρίδια είναι γραμμένα για ανθρώπους που **δεν** είναι εξοικειωμένοι με υπολογιστές:
ένα βήμα τη φορά, με τα ακριβή ονόματα των κουμπιών όπως φαίνονται στην οθόνη.

Εμφανίζονται και **μέσα στην εφαρμογή**, στο μενού «Βοήθεια» κάθε ρόλου
(`/portal/help`, `/marketplace/help`, `/staff/help`). Ό,τι αλλάζει εδώ, αλλάζει και εκεί.

## Συμβάσεις γραφής

- Ονόματα κουμπιών και μενού σε «εισαγωγικά», ακριβώς όπως στην οθόνη.
- Κάθε ενότητα ξεκινά με το «Πού το βρίσκω» και συνεχίζει με αριθμημένα βήματα.
- Όπου υπάρχει οδηγός βήμα-βήμα στην εφαρμογή, το λέμε: «Πατήστε … και ακολουθήστε τα βήματα».
- Χωρίς τεχνικούς όρους. Αν χρειάζεται ένας, εξηγείται σε παρένθεση την πρώτη φορά.
