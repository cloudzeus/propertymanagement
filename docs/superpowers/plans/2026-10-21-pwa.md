# PWA (εγκατάσταση στο κινητό + offline κέλυφος) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the Orithon app installable on phone home screens (manifest + icons + install banner) with a hand-written service worker that caches only the static shell and serves a Greek «Χωρίς σύνδεση» page when the network is down.

**Architecture:** `app/manifest.ts` (Next 16 metadata file convention, force-dynamic) built by a pure `buildManifest()`; `public/sw.js` hand-written with a pure `routeFor()` exposed on `self.__pwa` so vitest can load the file in a `node:vm` sandbox; client `PwaRegistrar` in the root layout; client `InstallBanner` (phone only, decision in pure `decideBanner()`) in AppShell and the report layout; `/home` redirect route as start_url; `/offline` public page precached at SW install.

**Tech Stack:** Next.js 16.2 App Router (Turbopack), React 19, TypeScript, vitest (node env), sharp (already in node_modules via Next), react-icons/ri.

**Spec:** `docs/superpowers/specs/2026-10-21-pwa-design.md`

## Global Constraints

- Greek UI copy everywhere; icons only `react-icons/ri` `*Line` variants; font sizes only `var(--fs-*)` tokens (no px font sizes); server components for data; inline style tokens (`var(--card)`, `var(--border)`, `var(--radius-sm)`, `var(--bg-canvas)`).
- No new npm dependencies. No database changes. Local `.env` DATABASE_URL is PRODUCTION: no test rows, no notifications.
- Build must not hit the DB: `app/manifest.ts` is `export const dynamic = "force-dynamic"`.
- proxy.ts matcher already skips paths containing a dot; `/offline` must be added to `authPublicPaths`. Never change the locale-rewrite logic.
- Service worker NEVER caches navigations, `/api/*`, RSC (`?_rsc=`), `/_next/image`, cross-origin. Cache-first only for `/_next/static/*`, `/icons/*`, `/apple-icon.png`; disabled when `?dev=1`.
- Colors: `background_color` and `theme_color` = `#F6F4EC`. Brand default name «Orithon»; `short_name` ≤ 12 chars.
- Do not touch `components/admin/sidebar-nav.tsx`, `lib/quick-actions.ts`, `lib/work/*`, settings/geodata (parallel sessions). Commit only files from this plan; never push, stash, reset or switch branch.
- Known pre-existing failures to ignore: 9 tsc errors, ~339 eslint errors repo-wide, 2 failing vitest files (`lib/building-caps.test.ts`, `lib/ai/assistant/actions.test.ts`).

## Review Focus

1. A navigation that returns an HTTP error (500) while online must be shown as-is, not replaced by `/offline` — only a rejected `fetch` (network failure) falls back. Pinned in Task 4 test «navigate with ok=false response passes through».
2. A `/_next/static` response that is not `ok` (404 chunk from an old build) must not be cached, or the stale 404 sticks forever. Pinned in Task 4 test «static non-ok response is not cached».
3. The install banner on a phone where `localStorage` throws (private mode) must still render and «Όχι τώρα» must not crash. Pinned in Task 5 test «readState/snooze swallow storage errors».
4. `companyName` longer than 12 chars must still produce a valid `short_name`. Pinned in Task 2 test.
5. The `/offline` page must render without a session (public) — otherwise the SW would precache the login page. Pinned in Task 3 by the proxy test asserting `/offline` is in `authPublicPaths`, plus manual browser check in Task 7.
